## 5. 补语料建议

1. 先补 P0 的宗教/民族习俗与做七/头七，直接覆盖文化习俗 14 条 needs_review 中的 P0 部分。
2. 再补 P0 心理知识 8 条；补完后可评估是否恢复心理疏导知识类查询。
3. P1 政策/补贴缺口数量最多（24 条），建议按「补贴/收费」与「审批/年限/迁坟」两批补。
4. P2 可随礼仪/用品内容扩充一并补；不阻塞阶段 1 基线。
5. 补文档后必须重新运行 `scripts/precheck_eval_retrieval.py`，并把对应 `needs_review` 改为 false；同时按 `docs/annotation-spec.md` 重新标注三态。

## 6. 与 150 条主集的关系

- 主集 41 条业务缺口全部在 `eval/golden_dataset/v1.yaml` 中，`needs_review: true`，不计入通过率分母。
- 8 条心理知识缺口不在主集中；若后续补回，需要占用 `跨意图 helpful` 或心理疏导的额度，并同步调整分布表。
- 本清单不改变 `min_score_bm25=0.15`，TD-001 仍为 `open`。
